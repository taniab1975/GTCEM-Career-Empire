# Career Empire Curriculum Journey Map

Working document for turning the Year 12 Careers and Employability syllabus into a logical game journey.

Source: `Careers-and-Employability-General-Year-12_Syllabus-for-teaching-from-January-2026.pdf`

## Core Design Rule

Curriculum appears when it makes story sense.

Students should not learn employment conditions before they have entered work. They should not learn grievance procedures before something has gone wrong. They should not practise interviews before there is a job opportunity. Skills and capabilities should appear as tools students need in order to respond to the story.

## Map Model

The game world has three linked layers.

### 1. Main Journey Road

The year-long story path:

Discover self -> explore work -> read the future -> make choices -> face disruption -> build capability -> apply -> interview -> enter work -> understand rights -> resolve problems -> grow again.

### 2. Knowledge Districts

Places where students learn how the world works.

Examples:

- Future Work District
- Labour Market Lookout
- Megatrends Centre
- Career Building District
- Workplace Rights Quarter
- Employment Conditions Office

### 3. Skills School

The Skills School is a reusable hub for capability practice.

It should not replace the story. It supports the story.

Students can visit Skills School directly from the map, but skills should also appear as interruptors during story events.

Likely Skills School modules:

- Communication Studio
- Digital Literacy Lab
- Teamwork Workshop
- Time Management Room
- Critical Thinking Lab
- Problem-Solving Lab
- Resilience Gym
- Adaptability Lab
- Initiative Workshop
- Interview Studio
- STAR / SAO / CAR Response Lab

Initiative should live in Skills School, but it should also be called into the main journey when the player faces a disruption, workplace problem, opportunity, or improvement challenge.

## EST Prep Rule

EST Prep should be separate from the main story map.

It can be accessed from the map through an EST Prep Lab, probably around the Term 2 checkpoint, but it should function as exam-training and response-practice rather than as the core curriculum journey.

EST Prep helps students practise:

- short answer responses
- extended answer responses
- stimulus interpretation
- terminology
- applying evidence
- test conditions

## Assessment Layer

Assessment should sit as checkpoints along the journey rather than random tasks.

| Assessment Type | Syllabus Weighting | Best Game Placement | Evidence Produced |
|---|---:|---|---|
| Investigation | 45% | Labour Market Lookout, Megatrends Centre, Workplace Rights Quarter, Grievance Office, Community Transformation zones | Research report, presentation, infographic, pamphlet, source analysis, case file. |
| Job Application And Interview | 20% | Job Opportunity Board, Application Workshop, Selection Criteria Lab, Interview Studio | Job ad analysis, cover letter, resume/other documents, selection criteria, interview evidence. |
| Response | 20% | EST Prep Lab and checkpoint response gates across the year | Short answer, paragraph response, retrieval chart, structured overview, extended response. |
| Externally Set Task | 15% | EST Prep Lab, around Term 2 timing | Timed 50-minute written response practice using stimulus materials. |

## Map Implications

The Phaser map should not be a set of equal buildings in a grid.

It should be a journey town with:

- a visible main road through the year
- side branches into Skills School
- district gates that unlock when story timing makes sense
- assessment checkpoints that feel like destinations
- community transformation zones that visually upgrade as class progress grows
- an EST Prep Lab that is accessible but separate from the main story spine
